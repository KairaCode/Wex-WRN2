# Research runs

One folder per dated lab run: the scripts, the raw output and, where one was written, the result file. Newest first.

**Run folders are frozen.** Nothing in them is edited after the run, except that personal and temporary paths were shortened to placeholders (`<KAIRA>` the KAIRA checkout, `<HOME>`, `<TMP>`, `<RESEARCH-PC>`, `<worktree>`, `<KAIRA-WT>`, `<SCRATCH>`), so the files are no longer byte-identical to the lab originals. On 2026-11-13 the value of `hostname_hash` (12 hex digits of a hash of the machine name) was replaced by `"<redacted>"` in the eight result files of `wnr-testkit-20261108/` that held it; the JSON stays valid. Drive letters (`U:`, `C:` and others) are those of the lab machine. Paths inside a run folder may name files that exist only in the KAIRA lab. Several result files are in Italian and stay as written.

The **verdict** column is copied from the file named in it, with the conditions that file gives. Open the **entry file** before quoting a number. The **KAIRA commit** column is filled only where a file of the run states it.

## The two archives

`wnr-testkit-20261108/` (774 files) and `wnr3-20261107/` (517 files) are the exploration behind WNR3: raw outputs, caches, per-team working folders and copies of each other. They are superseded by the final specification [docs/WNR3-SPEC.md](../docs/WNR3-SPEC.md) and by the verification run `wnr3-20261110/`. They stay in the tree because two things still read them:

- `wnr3-5090-20261107/g0/t2_g0.py` and `g0/t2_conformance_and_g_bins.py` load `wnr3-20261107/team4/ceil-ref`;
- the WNR3 specification names the drafts in `wnr3-20261107/team3/wnr3-spec/` and `team4/spec-update/` as its inputs.

Do not start a reading of the repository there.
