# WEX (resumen en español)

Resumen del [README en inglés](../../README.md) del 2026-11-15. El README en inglés es la referencia: donde los dos textos no coinciden, vale el inglés. Esta traducción no la escribió un hablante nativo; las correcciones son bienvenidas, con un issue o un pull request.

- **Qué es.** WEX es una familia de formatos de contenedor para los expertos de los modelos Mixture-of-Experts: un archivo de records alineados a 4096 bytes, uno por cada routed expert, que el motor lee desde NVMe con una sola lectura mientras genera. WEX4 añade una header page y un índice con el SHA-256 de cada record; WNR3 es la codificación rANS sin pérdida de los records. WEX4 (versión de formato 4.0) y WNR3 (v1) están congelados; el código es la implementación de referencia, de nivel de investigación y pensada ante todo para Windows.
- **Qué funciona hoy** (resumen del 2026-11-13). DeepSeek V4.1 REAP-192 lee un WEX4 con records WNR3 (0.854 del tamaño sin comprimir), Qwen3.8-Flash-Next un WEX4 con records MXFP4 sin comprimir (RAW); ambos desde dos unidades NVMe (U: y C:, lecturas repartidas 38/62). Estado actual: [STATUS.md](../../STATUS.md).
- **Cómo probarlo.** `bash scripts/check_all.sh` compila y ejecuta las comprobaciones en CPU (tests de los formatos, lectores y convertidores WEX4, vectores de conformidad, el decodificador WNR3 rápido) y la comprobación del repositorio, sin GPU y sin modelos; si todo va bien, la última línea es `all checks passed`, con código de salida 0. Los requisitos están en la sección [Try it in ten minutes](../../README.md#try-it-in-ten-minutes) del README. La CI lo ejecuta en Linux (x86-64 y ARM64), macOS (Apple silicon) y Windows.
