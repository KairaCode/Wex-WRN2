# scripts/

**Current.** Build and check scripts that exist only in this repository. They used to sit among the mirrored files; `c/` now holds nothing but KAIRA's files.

- `check_all.sh`: every check of this repository that needs no GPU, no model and no KAIRA tree, in one command: `check_repo.py` (self-test and check), the three standard-library tests below, `build_cpu_check.sh` and `wex4/build_and_test.sh`. Run `bash scripts/check_all.sh` from anywhere; last line on success: `all checks passed`. It is what CI runs.
- `build_cpu_check.sh`: the CPU self-test of `c/`, no GPU and no real model. It builds and runs `c/tests/test_wex_format.c` and `c/tests/test_wex4_verify.c` (the WEX4 checker `c/tools/wex4_verify.c` on small synthetic WEX4 files: an intact file passes with the expected root, changed records, padding, blobs, index and header page fail; it prints one summary line), compiles `c/tools/wex4_verify.c` alone, compiles the WNR3 encoder DLL and the CPU stand-in helper, then builds a WEX1, WNR3-CZ bins and a WNR3-CZ container from `fixtures/v41-tiny`. Run `bash scripts/build_cpu_check.sh` from the repository root with MSYS2 UCRT64 or MINGW64 `gcc` on `PATH`; last line on success: `WNR3 CPU check passed`. The summary line `"gate_failures": 144` above it is not an error: it counts the matrices (48 records x 3) of the tiny fixture on which ceil-form was not used. Output goes to `out/cpu-check/` (git-ignored). With a KAIRA `src/colibri/c` folder as first argument it also builds and runs `c/tests/test_expert_store_wex.c`, which needs engine headers.
- `verify_wex1.py`: byte check of a WEX1 / WEX2 / WEX3 container against the safetensors checkpoint it was built from: `python -I scripts/verify_wex1.py --model-dir DIR --wex FILE [--stride N]`. It rejects a WNR2 container (check that with `archive/nr2/check_container.c` or `archive/nr2/check_all.py`); WNR3 and WEX4 are outside its scope (for WEX4: `python -I wex4/wex4.py verify FILE`).
- `test_verify_wex1.py`: its test on a synthetic model, `python -I scripts/test_verify_wex1.py`.

The repository check, [`../check_repo.py`](../check_repo.py), is at the root. The GPU builds are in [`../integration/build/`](../integration/README.md); the WEX4 tests are run by [`../wex4/build_and_test.sh`](../wex4/README.md).
